# Dedicated animated TrackBadge integration

Compile TrackBadgeArtProvider.cpp and TrackBadgeArtworkLoader.cpp. Load track-badge-ui.ownedz with nfs_track_badge_art_load_file before the game worker starts. TrackBadgeArtworkPin.h is deliberately empty until the private pack is authenticated. Never substitute the PlayerPhoto pin. Failure leaves the entire native path in place.

The file format follows PlayerPhoto schema1:16-byte header (8-byte NFSTRBDG, LE32 version1, LE32 uncompressed payload size), then one exact zlib stream. Payload:LE32 imageCount18, LE32 flags0, then18 image records. Each record has LE32 sourceIndex,width1024,height1024,flags0; eight LE binary32 values for logical and focal bounds; then1024*1024*4 premultiplied RGBA bytes. Logical bounds must be(0,0,256,256); focal bounds must be nonempty inside that canvas. The whole compressed file SHA256/size and payload size are compile-time pinned. Installation is immutable, all18 images are mandatory, pixel digests and PMA channels are validated, retained views own their lifetimes.

IDs0..15 are track*2+(rec7?1:0), in native order oval,oz,lrt,nort,pac,med,myst,mono. IDs16/17 are lastrec rec6/rec7:those resources differ from lrtinfo. Other seven Records resource byte spans match their info counterparts, but have independent archive/directory/offset admission records.32 catalogue rows cover all16archives, including rec7 metadata. Only actual named rec6 consumers in41C1B0,41B8D0,41C850 are admitted. No rec7 consumer is inferred or enabled.

Registration is the actual428140→405B60 flags1900→486C60 draw position:x=[49,18,56,53,49,56,50,58],y0. This path does not apply intrinsic header origin+0xC (that belongs to the different486D10 path). Artwork must already occupy this registration on the256-square canvas; preserve independent rec6 shadow and rec7 shadowless authoring. Raw header fields are not placement authority.

Run scripts/classic_screens/track_badge_hooks.py on the composed generated source (fallback-dir supported). It adds only observers to units1,2,3,10,12, and checks exact inverse removal before publishing its source receipt. Original calls, values, control flow, source images, staging allocation/free,1555 upload, animation, color, and both native triangles remain in place.

The producer checks the actual selected native track index, exact archive/directory entry/offset/full raw source digest (including embedded palette), the resolved pointer/1900 flags, selected256-square32-bit staging window/clip, zero clear, actual486C60 draw and its owned output,200-alpha conversion of all65536 words, exact4D4E44 descriptor/payload/key, actual staging retirement, owner/thread/epoch, and retained artwork generation. It owns source/staging/upload bytes before the original temporary window is freed. Repeated draws compare retained source identity and descriptor without full image SHA or private texture reupload.

Renderer wiring requires created,retired,upload_begin,upload_done,select,triangle. The dedicated actual256 upload witness and overlap invalidation maintain texture epochs independently of the global32-pixel NativeMark profile. Renderer checks context/thread/native object/address/rotated1555 bytes, exact lod/format/parity, framebuffer/viewport/projection, and both actual60-byte native triangle vertices. Four fully constructed original497D6C vertices are captured immediately before its first real grDrawTriangle, without synthesizing pose, UV, tint, or positions. Only their two exact native triangles may bind the private texture, and original binding is restored after a flushed batch. Authored PMA is converted once to straight alpha for the existing native shader/blend contract; original1555 alpha is never treated as continuous alpha.

Coverage is source implementation and insertion preservation. Grouped compilation, renderer execution, pixel inspection and physical-device acceptance remain separate gates. Empty pins deliberately make this path fall back.
