# Class picture integration boundary

A separate optional resource keeps PlayerPhoto's existing twelve-car policy unchanged. ClassPicture accepts exactly three1224x584 RGBA PMA collages on logical(0,0,306,146). Partial sets, duplicate roles, wrong dimensions/digests and non-PMA pixels are rejected. Transparent collage margins are permitted. Installation copies pixels once; acquired views retain immutable storage even after provider clear.

Resource: class-picture-ui.ownedz, magicNFSCLPIC, schema1. It reuses PlayerPhoto's16-byte file header, exact zlib stream and48-byte image records. Roles0/1/2 represent clsa/clsb/clsc only after independent source authentication. The file, payload size and SHA256 must be generated privately; the public default pin is empty and loading fails closed. Compressed file and decoded payload each cap at9MiB. Three images use8,577,792 raw pixel bytes; metadata adds152bytes. Verify actual ZIP/IPA budget after accepted pack generation.

Load before starting the worker. No startup/CMake/renderer hookup is included here. The consumer must authenticate original main.qfs and decoded archive, exact clsa/clsb/clsc full-source SHA256, directory entry/offset/span, resolved original405B30 consumption, source/staging lifetime and original upload witness. Private source identities belong in a generated independently pinned catalogue, never in the untrusted image records.

Only actual form4D3204 may route selector byte512DF5 values12/13/14 to provider roles0/1/2, while byte512DF6 enables preview. Recheck game/thread/epoch and current source selection before publication and again before native presentation. Retain the acquired art view through any queued renderer callback. Native address/object/upload revision/context generation, exact original geometry/UV/blend and full proof ownership remain mandatory. A provider role or successful artwork lookup alone grants no rendering authority.

Do not reuse A5/B5/C5 small badges, text class-label SVGs, or PlayerPhoto car roles. The authored306x146 collages remain pending vehicle-identity review; no draft is selected by these files.
