Slideshow compatibility metadata

SPDX-License-Identifier: MIT

SlideshowCatalogData.h and SlideshowFooterData.h contain code compatibility
fingerprints, resource offsets, sizes, dimensions, layout/version fields and
routing bindings. They contain no drawable image arrays, compressed image
payloads, original game asset files, personal paths or reference photographs.

Source archive/entry SHA-256 values identify user-supplied original data; a
fingerprint is compatibility metadata, as in CarInfoSourceCatalog.h. Resource
fingerprints identify separately supplied replacement artwork and do not
redistribute that artwork. The corresponding .ownedz image resources remain
separate inputs; this metadata approval does not approve their publication.

These metadata headers are separately reviewed under the project's MIT
license. They do not change the nine-header authored/OFL artwork approval in
APPROVED_ASSETS.json or confer a license to game artwork, names or trademarks.
