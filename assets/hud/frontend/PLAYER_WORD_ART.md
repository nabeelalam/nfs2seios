# Player text artwork

This asset contains thirty fixed text graphics, including a single colon punctuation allocation. It contains no font file, reusable alphabet, font renderer, or original game pixels. The graphics preserve the existing Player word allocations, crops, source glyph geometry, and layout. Nineteen graphics are shared with other menu families: there are 56 approved uses in total, including 26 additional aliases. Options shares the fixed colon, on, and off allocations in addition to the Location/Setup/Opponents uses. The existing Main menu graphics are independent and unchanged.

The reviewed text was authored with Haettenschweiler at a consistent weight and condensation. Complete text images, rather than a font, are distributed. See the [Microsoft font redistribution FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq#redistribution-and-extended-rights) for the distinction between graphics produced using a font and redistribution of font software.

`player-word-art-0.json` and `player-word-art-1.json` are the finite source: exactly fifteen fixed text graphics per part. Both compact JSON files remain below the 1 MiB publication gate. Each record identifies its exact text, fixed atlas rectangle, original source crop, approved shared uses, decoded RGBA SHA256, and alternating alpha run lengths/values. All RGB channels are white, including transparent pixels. The decoder pins both source files independently and all thirty decoded images, checks every actual family placement and alias before writing, and replaces only those fixed allocations. It does not change glyph geometry or add rendering coverage. The colon remains one fixed punctuation image at its existing allocation; it is not an API for rendering arbitrary punctuation or text.

Full generation applies this artwork after deterministic packing and the independent Main word override. Layout-only generation must validate the same two selected-project source files and exact final family placements against the recorded metadata. Updating the art or packing requires an explicit source/hash and fixture review. These fixed text graphics do not require Haettenschweiler installed on the build host; historical base packing still uses the bundled OFL fonts.
