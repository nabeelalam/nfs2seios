# Child Controls native rendering

The original single-player and split-screen Controls setup screens now use an independent native HD route. Fixed action names, headings, prompts and buttons use 28 authenticated whole-word images in the lighter condensed style. Supported keyboard and controller binding values now use 360 complete phrase images in the same lighter condensed style, with the original source-16/source-18 advances. These cover printable/named keys, both controller slots, axes, buttons and the unassigned value. Each phrase replaces only an exact matched sequence of immutable original text commands; unsupported strings, exceptional spacing or clipped layouts keep their original rendering.

The child route joins the existing complete source-frame and retained sidebar evidence, then independently checks the original 300 uploads, 300 selections and 600 triangles before committing only the staging color. Parent Controls policy remains separate. The maintained source preparation installs reversible hooks and copies the child helpers; it needs no new cloud work to generate them.

Pixel authentication occurs before uploading new owned label textures. Cached draws use those fixed authenticated GPU copies and validate text spans, image metadata, aliases and current context each pass. The old implementation hashed 3,457,024 image bytes five times per menu frame; cached label draws now perform no image-payload hashes or texture uploads. This removes demonstrable redundant work, without claiming a measured iPad battery improvement.

Thirteen registered tests pass with address/undefined-behavior checks. The actual GLES test reads back all 28 textures, rejects corrupt fresh pixels, exercises cached reuse and new-generation reauthentication, preserves leading/intervening/trailing dynamic text, and restores inherited GL state. Synthetic test results grant no original-game source authority.

Separate owned-window original-game tests pass for single-player and both split-screen player columns at 2186 by 1640. Each assignment prompt opens and cancels without changing the original binding words; the screens return through Controls, Options and Main, then close normally. Source replay covers all 307,200 words, including ordinary and assignment screens. Copied configuration and artwork are restored after each run. Private captures and logs remain outside Git; the source-only evidence record contains their hashes and scope.

This is local render acceptance, not a new iPad release or final artwork approval. Broader UI review and physical iPad performance/battery checks remain open. No cloud build or paid service was used for this milestone.

Binding phrases retain their source packet and immutable image owners. The CPU decodes only requested phrases and retains at most 40 cached images. The renderer owns at most 20 current phrase textures, authenticates missing pixels before GL work, and reuses warm textures without payload reads or uploads. It merges fixed labels, complete phrase shadow/foreground layers and intervening original text in original source-span order. Actual overlapping component boxes refuse whole-phrase replacement. Cache eviction preserves textures inherited on other texture units; context loss forgets ownership without further GL calls.

The three added checks cover all 360 identities and image hashes, exact grammar/geometry matching, immutable lifetime through eviction, clipped/unsupported fallback, real GLES pixel readback, corrupt cold-image refusal, warm reuse, context changes, inherited state, and combined fixed/phrase/original draw ordering. These tests complement original-game acceptance; they do not prove physical iPad performance.

Normal build preparation explicitly installs the child text, sidebar and complete-frame collectors before installing the child scene hook. A missing dependency previously left the private integration executable working while the normal preparation path had only the presentation hook. The pipeline regression test reads the real preparation entry and checks imports, unconditional per-unit calls, dependency order and output; mutation cases demonstrate that omissions fail. It also composes and reverses all four child hook families across the six public synthetic units. Runtime acceptance must use a clean normally prepared executable, without private source observers, as well as the earlier detailed private proofs.
