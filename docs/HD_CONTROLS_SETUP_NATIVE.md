# Child Controls native rendering

The original single-player and split-screen Controls setup screens now use an independent native HD route. Fixed action names, headings, prompts and buttons use 28 authenticated whole-word images in the lighter condensed style. Original key/controller strings remain dynamic, in their existing immutable font catalog, between the replaced spans. Their visual font still needs harmonizing.

The child route joins the existing complete source-frame and retained sidebar evidence, then independently checks the original 300 uploads, 300 selections and 600 triangles before committing only the staging color. Parent Controls policy remains separate. The maintained source preparation installs reversible hooks and copies the child helpers; it needs no new cloud work to generate them.

Pixel authentication occurs before uploading new owned label textures. Cached draws use those fixed authenticated GPU copies and validate text spans, image metadata, aliases and current context each pass. The old implementation hashed 3,457,024 image bytes five times per menu frame; cached label draws now perform no image-payload hashes or texture uploads. This removes demonstrable redundant work, without claiming a measured iPad battery improvement.

Ten registered tests pass with address/undefined-behavior checks. The actual GLES test reads back all 28 textures, rejects corrupt fresh pixels, exercises cached reuse and new-generation reauthentication, preserves leading/intervening/trailing dynamic text, and restores inherited GL state. Synthetic test results grant no original-game source authority.

Separate owned-window original-game tests pass for single-player and both split-screen player columns at 2186 by 1640. Each assignment prompt opens and cancels without changing the original binding words; the screens return through Controls, Options and Main, then close normally. Source replay covers all 307,200 words, including ordinary and assignment screens. Copied configuration and artwork are restored after each run. Private captures and logs remain outside Git; the source-only evidence record contains their hashes and scope.

This is local render acceptance, not a new iPad release or final artwork approval. Dynamic binding typography, broader UI review, and physical iPad performance/battery checks remain open. No cloud build or paid service was used for this milestone.
